# Java Collections Framework

The Java Collections Framework provides a unified architecture for representing and manipulating collections of objects.

## Core Interfaces
- **List**: An ordered collection that allows duplicate elements (e.g., ArrayList, LinkedList).
- **Set**: A collection that contains no duplicate elements (e.g., HashSet, TreeSet).
- **Map**: An object that maps keys to values, supporting unique keys (e.g., HashMap, ConcurrentHashMap).

## Key Implementations
ArrayList is backed by a dynamically resizing array, offering O(1) random access time complexity.
HashSet uses a HashMap under the hood for constant-time basic operations like add and contains.
