# 05 - Maven Build Lifecycles and Phases

Apache Maven operates on the concept of a **Build Lifecycle**. A lifecycle is a defined sequence of build steps (called **phases**) that dictate the order in which goals are executed.

---

## The Three Built-in Lifecycles

Maven has three independent built-in lifecycles:

1. **Default Lifecycle**: Handles project compilation, testing, packaging, and deployment.
2. **Clean Lifecycle**: Handles project cleanup (deleting previously generated build outputs).
3. **Site Lifecycle**: Handles creation and generation of project documentation and site reports.

---

## 1. The Default Lifecycle Phases

When you execute a command like `mvn package`, Maven sequentially executes every phase in the Default Lifecycle up to and including `package`.

The main phases of the Default Lifecycle in order of execution:

| Phase | Description |
| :--- | :--- |
| **`validate`** | Validates the project structure and ensures all necessary information is available. |
| **`compile`** | Compiles application source code located in `src/main/java`. |
| **`test-compile`** | Compiles test source code located in `src/test/java`. |
| **`test`** | Runs unit tests using test frameworks (JUnit, TestNG). |
| **`package`** | Takes compiled code and packages it into its target format (e.g., JAR, WAR). |
| **`verify`** | Runs integration tests and checks quality metrics. |
| **`install`** | Installs the packaged artifact into the local Maven repository (`~/.m2/repository`). |
| **`deploy`** | Copies the final package to a remote Maven repository (Nexus/Artifactory) for sharing. |

---

## 2. The Clean Lifecycle Phases

The Clean Lifecycle consists of three sequential phases:

1. **`pre-clean`**: Executes processes required prior to actual project cleaning.
2. **`clean`**: Deletes all files generated by previous builds (removes the `target/` directory).
3. **`post-clean`**: Executes processes required immediately after project cleaning.

Example Command:
```bash
mvn clean package
```
This command runs the `clean` lifecycle phase (deleting `target/`), followed by the `package` phase of the default lifecycle (compiling and packaging fresh outputs).

---

## 3. The Site Lifecycle Phases

1. **`pre-site`**: Prepares for site generation.
2. **`site`**: Generates project documentation site.
3. **`post-site`**: Finalizes site generation.
4. **`site-deploy`**: Deploys generated documentation to web server.

---

## Phases vs. Goals

* **Phase**: A step in the Maven lifecycle (e.g., `compile`, `test`, `package`).
* **Goal**: A specific task bound to a phase, provided by a Maven plugin (e.g., `compiler:compile`, `surefire:test`).

When a phase is executed, Maven executes all plugin goals bound to that phase in order.

```text
Phase: package  ──► Executed Goal: maven-jar-plugin:jar
```
